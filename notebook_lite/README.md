# Notebook data audit

גרסה עצמאית ורזה של הניתוח: סקריפטים רגילים ומחברת, ללא התקנת הפרויקט כחבילה וללא תלות ב־GUI או בקוד בתיקיית האב. אפשר להעתיק את כל התיקייה למקום אחר.

## התחלה

נדרש Python 3.11–3.13. מתוך התיקייה:

```sh
python setup_local.py
.venv/bin/python -m jupyterlab analysis.ipynb
```

ב־Windows הפקודה השנייה היא:

```bat
.venv\Scripts\python -m jupyterlab analysis.ipynb
```

במחברת משנים את נתיב ה־CSV ושמות עמודות המזהה, התווית והפיצ׳רים ומריצים מלמעלה למטה. `demo.csv` הוא מידע סינתטי בלבד. המחברת כוללת תוצאות הרצת דוגמה; לאחר החלפת הנתונים יש להריץ מחדש את התאים.

כל הקוד נמצא כאן: `analysis.py` לניתוח שכנים ו־OOF חוזר; `representations.py` לייצוגים; `scoring.py` לחישוב ציונים; `explore.py` לגרפים, ספים, סיכומים, חקירת דגימות וייצוא. אין registry, מחלקת תוצאה, binding או פורמט של UI. הפלט הוא מילון של טבלאות pandas, עם `samples` לפי מזהה דגימה, טבלאות ראיות ופרטי הקיפולים. מוסיפים פונקציות ותאים כרצונכם.

המחברת מדגימה מרחקים/ייצוגים מותאמים, הגבלת רדיוס ותמיכה, בידוד קבוצות ב־OOF, חקירת שכנים וראיות לפי מחלקה, פיזור אינטראקטיבי, היסטוגרמה, חפיפה בין מחלקות, השוואת שיטות, סינון, סיכום מטא־דאטה, הערות סקירה וייצוא מלא/מסונן/נבחר. ניתן להשתמש גם ב־Excel דרך pandas. העיבוד מקומי וסינכרוני; עוצרים דרך Interrupt Kernel.

כל התלויות הנדרשות מותקנות ב־`.venv/` שבתיקייה. `setup_local.py` גם מוריד את התלויות הטרנזיטיביות ל־`wheels/`, כך שבהמשך אפשר להריץ `python setup_local.py --offline`. תיקיות `.venv/`, `wheels/` ומטמון ההתקנה נשמרות מקומית ואינן מועלות ל־Git. לאחר clone יש להריץ `python setup_local.py` בחיבור לרשת; לאחר מכן ניתן לעבוד לא מקוון. הגלגלים שהוכנו מקומית נבדקו ב־Linux x86_64 עם Python 3.12; במערכת אחרת מריצים הכנה מקוונת. סביבת venv אינה ניידת: אחרי העתקת התיקייה יוצרים אותה מחדש מתוך הגלגלים. `requirements.lock.txt` מתעד את כל הגרסאות שנבדקו.

Autoencoder נתמך ב־`AutoencoderEmbedding`, אך PyTorch הוא תוסף כבד ואינו מותקן כברירת מחדל. להתקנה בתוך אותה תיקייה: `.venv/bin/python -m pip install --cache-dir .pip-cache torch`. לעבודה לא מקוונת יש להוריד גם את גלגלי PyTorch והתלויות שלו ל־`wheels/` על המחשב המתאים. אין צורך ב־PyTorch לשאר המחברת.

הניקוד והבדיקות המספריות שומרים על לוגיקת השיטות המקורית. ציונים אינם הסתברות לתווית שגויה. הספים לדוגמה מצריכים כיול. חוסר תמיכה מוביל לדגל חסר, וסטיית תקן בין חזרות אינה רווח סמך. אין שינוי אוטומטי של תוויות או טיפול שקט בנתונים חסרים.

שמירה נעשית במחברת עצמה, CSV, JSON פשוט לפרטי קיפולים ו־HTML עצמאי לגרפים; אין תמיכה בפתיחת `.audit.zip` הישן, בניהול jobs של ה־GUI או בסנכרון בחירה אוטומטי בין גרף לטבלה. בוחרים מזהים ומסננים באמצעות Python. CSV אינו שומר את כל טיפוסי pandas; בהטענה חוזרת יש לציין `dtype` לפי הצורך.

בדיקות: `.venv/bin/python checks.py`. הרצת המחברת: `.venv/bin/python -m jupyter nbconvert --to notebook --execute --inplace analysis.ipynb`.

אימות שבוצע: שש בדיקות ממוקדות עברו (מזהים, שכנים עצמיים, תמיכה, סדר אינדקסים, בידוד קבוצות ואימון ייצוג בתוך קיפול, וחזרה יחידה). ציוני השכנים בשלושת מצבי הרדיוס ו־OOF חוזר הושוו למימוש המקורי ותאמו בסבילות מוחלטת `1e-12`. המחברת הורצה במלואה וגם לאחר העתקת הקוד לתיקייה מחוץ לפרויקט; הכנה לא מקוונת נבדקה עם הגלגלים המקומיים. PyTorch האופציונלי לא נבדק מחדש בגרסה זו.
